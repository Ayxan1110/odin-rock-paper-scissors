# Rock Paper Scissors

Project from [The Odin Project – Foundations, JavaScript Basics](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).

**Live demo:** https://ayxan1110.github.io/odin-rock-paper-scissors/

Play against the computer. The first one to get 5 points wins.

## What I used
- `Math.random()` to make the computer choice
- Functions with parameters and return values (`getComputerChoice`, `playRound`)
- Conditionals (`if / else if / else`) and logical operators to decide the winner
- DOM manipulation and click events (from the "Revisiting Rock Paper Scissors" lesson)
